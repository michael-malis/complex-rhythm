How complex roots become rhythms

Each instrument has a complex number z = a + bi and a root degree n. For nonzero z, its n roots have equally spaced arguments. We interpret those angles as moments in a repeating cycle. A cycle is normally one bar; the Bossa Nova example spans two.

Changing the argument rotates the base events. Changing |z| without changing its argument does not affect their timing. The four circle radii separate instruments visually; they are not the actual moduli of the roots. When z = 0, the base layer has no rhythmic events. Extra root sets can be combined to create less regular patterns.

Drag a base root point to rotate its set, or use the arg(z) slider. On the focused canvas, Shift + ←/→ rotates the set by 5°. Space toggles playback; arrow keys select tracks. Sound is an additional way to perceive the geometry.
